## 任務背景

M487_ScsiTool 的最終目標是 MSC + HID I2C Bridge 複合裝置。但在那之前，需要先確認：
1. **M487 USB High Speed MSC 可以正常運作**
2. **GCC 編譯 + OpenOCD 燒錄流程暢通**
3. **Host 端能看到 USB Storage**

BSPSampleCode 中的 `HSUSBD_Mass_Storage_ShortPacket` 是乾淨的參考起點。

---

## 研究目標

### 1. KEIL 專案分析
- 分析 KEIL `.uvprojx` 了解編譯、連結、燒錄設定
- 研究 `Nu_Link_Driver.ini` 的燒錄配置
- 確認燒錄演算法（Flash algorithm）和起始位址
- 確認燒錄後 MCU 的啟動行為

### 2. BSP Library 結構分析
- `Library/Device/Nuvoton/M480/Source/` — CMSIS startup、system_m480.c
- `Library/StdDriver/src/` — hsusbd.c, clk.c, uart.c 等
- 這些是 KEIL 專案的 linked resources，需要確認 GCC 版本是否存在

### 3. GCC 編譯可行性評估
- 確認 GCC 版本的 startup code (`startup_M487.S` 或 `.c`)
- 確認 Makefile 需要的 library path
- 評估將 KEIL 燒錄設定移植到 OpenOCD 的方式

### 4. OpenOCD 燒錄驗證
- 將 KEIL 的燒錄設定轉換為 OpenOCD script
- 測試燒錄成功、執行成功
- 驗證 Host 端 USB 枚舉（應該出現 USB Mass Storage Device）
